# Unidade 4: Consolidação de KPIs, Métricas de Severidade e Preparação do Dashboard

Unidade de encerramento do Módulo 1, focada na consolidação dos dados processados, cálculo dos indicadores-chave e estruturação dos dados para ferramentas de BI.

## Objetivos de Aprendizagem
- Consolidar as bases trabalhadas em uma camada pronta para consumo de visualização (*Gold layer* / *Data Mart*).
- Definir e calcular os KPIs oficiais do projeto (Índice de Severidade, Taxa de Mortalidade por 100 acidentes, etc.).
- Elaborar o wireframe / protótipo do dashboard de acidentes da PRF.

## Tópicos Cobertos
- **Engenharia de Features:** Criação de colunas calculadas (ex: indicador de acidente fatal, período do dia).
- **Métricas Chave (KPIs):**
  - Total de ocorrências vs. Total de vítimas.
  - Taxa de severidade por causa presumida (ex: ultrapassagem indevida, velocidade incompatível).
  - Variação percentual de acidentes ano a ano (YoY).
- **Exportação de Dados:** Geração de arquivos estruturados (`.csv` / `.parquet`) otimizados para ferramentas de BI (Power BI, Streamlit ou Tableau).

## Tecnologias e Métodos
- **Processamento Final:** Python (`pandas` / `pyarrow`).
- **BI / Visualização:** Estruturação para dashboards interativos.

## Entregável da Unidade
- **Atividade 4:** Base consolidada final, documentação completa dos KPIs e o esboço/protótipo do painel de controle interativo.
